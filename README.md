## 🌟 Highlights & Features

- 🎨 **Dynamic Multi-Theme Engine**: Switch between 4 color palettes on the fly:
  - **Cyberpunk Neon**: Electric Cyan (`#00f5ff`) & Hot Magenta (`#ff007f`)
  - **Cosmic Aurora**: Deep Violet (`#a855f7`) & Celestial Blue (`#38bdf8`)
  - **Hyper Matrix**: Toxic Emerald (`#00ffaa`) & Cyber Mint
  - **Sunset Lava**: Radiant Coral (`#ff5e36`) & Golden Amber (`#fbbf24`)
- ✨ **Interactive Background Canvas**: Real-time constellation particles that interact with mouse proximity and shift color based on the selected theme.
- 💻 **Interactive CLI Terminal**: Recruiter-friendly built-in terminal supporting commands (`about`, `skills`, `projects`, `experience`, `education`, `certs`, `contact`, `theme [name]`, `matrix`, `clear`).
- 🔊 **Zero-Asset Web Audio Synthesizer**: Procedural synthesized UI clicks and melodic chimes via HTML5 Web Audio API (with instant mute toggle).
- 📱 **Interactive Project Filter & 3D Tilt**: Real-time filtering (Mobile, AI/Web, Systems) and silky 60fps 3D card tilt physics.
- 🔍 **Project Deep Dive Modals**: Detailed architectural breakdowns, challenges solved, and GitHub links for each project.
- 📄 **Interactive Resume Modal & Print Engine**: Built-in resume viewer with ATS-friendly print styles (`Ctrl + P` / 1-click PDF export).
- 📋 **One-Click Contact Actions**: Instant clipboard copy for email (`yashsamsukha10@gmail.com`) and phone (`+91 7020961022`) with toast notifications.
- ⏰ **Live Pune Time Clock**: Real-time IST clock in the footer.
- 📱 **100% Responsive**: Tailored for mobile screens, tablets, laptops, and ultra-wide displays.

## 🚀 How to Run Locally

You don't need any complex build tools or dependencies! You can run it immediately using any of the following methods:

### Method 1: Direct File Open
Simply double-click [`index.html`](file:///c:/Users/yashs/OneDrive/Desktop/Project%20management/Portfolio/index.html) in Windows File Explorer to open it in your browser (Chrome, Edge, Firefox, Brave).

### Method 2: Local HTTP Server (Recommended)
Using Python:
```bash
python -m http.server 3000
```
Or using Node.js:
```bash
npx serve
```
Then visit `http://localhost:3000`.
